acquaint#

acquaint: people, and what they are involved in, for AI agents.

Who someone is, how to reach them, how to read them, how to write to them, kept as hand-editable Markdown with a source on every preference, outside any code repository.

The verbs are the same in Python, on the command line (acquaint who ada -f aka) and over MCP:

>>> from acquaint import new, remember, who, brief
>>> new("person", "Ada Lovelace")
>>> remember("ada-lovelace", "prefers email for anything with attachments",
...          source="https://example.org/thread/1")
>>> who("ada", field="aka")["value"]
['Ada', 'Lovelace']

For library use, Store is a MutableMapping of entities over any mapping of files (a dol files store by default).

class acquaint.Entity(store, key)[source]#

Bases: MutableMapping

One person, project, org or group: a mapping of its files (relative names to text), plus parsed views of them.

Parsed views are recomputed on access (these are small text files), so an edit made through the mapping is never hidden behind a stale cache. Parse problems are collected in errors; they never raise.

Ordered channels for reaching someone in a context. Only active addresses; returns them, sends nothing. outcome is reachable, no_address (a rule matched, but neither states an address nor finds a usable one recorded for its channels) or no_channel. Each channel’s address_kind is stated, identity (the person’s handle, which a conversation-addressed channel does not take) or None.

acquaint.remember(entity, text, *, source=None, kind='observation', disclosed=None, reactivate=False, data_dir=None)[source]#

Append a dated observation (observation, interaction, identity, preference, view, rule) to an entity’s log, with its source. An interaction may list the records the message identified (disclosed: exact ids, never the text). An identity equal to an inactive one (stale, retracted, …) is refused, naming that entry and the command with which the operator can make it active again.

acquaint.who(name, *, field=None, brief=False, data_dir=None)[source]#

Look up one person, project, org or group by exact id, name, alias, handle or email.

Costs scale with what you ask: field returns one value (aka, email, github, label, tier, any frontmatter key), brief the identity block, and the default the whole entry file. It never guesses: no exact match, or several, returns the candidates and ok: false.

Return type:

dict

Modules

deslop

The deterministic half of deslop: find the patterns that make prose read as machine-written, scaled to the reader.

edit

Changing the store: create an entity, append an observation, rename with relinking, forget with a tombstone.

lookup

Finding the right record: exact references, handle resolution, the conflation check, and channel choice.

mcp

MCP over stdio: the same tools, for Claude Desktop and other local MCP clients.

records

The text formats acquaint stores, as pure functions: frontmatter, sections, items, source tags, slugs, log entries.

render

Turning a tool's result into terminal output: (stdout, stderr, exit code).

resources

Files shipped inside the package: record templates, the policy tripwires, purpose reminders, the tells catalogue, skills.

store

Where records live and how code reaches them: the data root, Store and Entity.

sync

Private-repository sync for the data root: create the repository private, refuse anything else, guard every push.

tools

The single source of truth for every surface: plain functions, flat arguments in, JSON-ready dicts out.

trust

The disclosure vocabulary: tiers on people; labels, seals and clearances on records; and which tier is in force.
