acquaint.__main__

acquaint on the command line: cw over acquaint.tools.TOOLS, with sync_* as a sync group.

--json anywhere prints the tool’s result dict instead of text; - as the text of check or style-lint reads it from stdin. The exit status is the same either way (acquaint.render.exit_code()).
